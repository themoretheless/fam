# Наш быт

Семейный трекер дел с очками. Два игрока, посередине очередь дел, отсортированная
по срочности. У каждого дела есть срок сгорания: чем дольше дело висит, тем больше
очков за него дают (от x1.0 в момент создания до x3.0 у дедлайна). Не успели - дело
сгорает, и оба игрока получают штраф.

## Возможности

- Очки растут со временем, забирает тот, кто успел (кнопки или свайп карточки
  влево/вправо на тачскрине)
- Сгорание с огненной анимацией и штрафом обоим игрокам
- Комбо-множитель x1.25 / x1.5 за несколько дел в течение часа
- Повторяющиеся дела (чип «повторять»: после выполнения или сгорания дело
  возвращается в очередь)
- Ачивки (первое дело, «Пожарный», «Сова», комбо-мастер и другие)
- Уровни и титулы из XP, кольцо прогресса вокруг аватара
- Недельные сезоны: в понедельник счёт обнуляется, победителю - сезон в копилку
  (XP не сгорает никогда)
- Панель статистики: график очков по дням за 14 дней, итоги недели
- Общая семейная полка своих шаблонов дел: изменения синхронизируются между
  телефонами вместе с остальным состоянием
- Семейный календарь памятных дат: годовщины, день встречи, дни рождения и
  другие ежегодные события с ближайшими датами и счётчиком лет/дней
- Живая синхронизация между устройствами через SSE
- Звуковые эффекты на WebAudio (переключатель в шапке)
- Лента событий, корона лидера, конфетти
- Три темы: тёмная, «бумажная» (блокнотный лист в линейку, цветные карандаши,
  рукописный шрифт) и «карандашная» (графитовый набросок в альбоме: всё
  обесцвечено, штриховка и двойные контуры); переключатель в шапке по кругу,
  выбор запоминается

## Запуск

Бэкенд (Rust, порт 7878):

```bash
cargo run --manifest-path backend/Cargo.toml
```

Фронтенд в режиме разработки (Vite, порт 5173, проксирует /api на 7878):

```bash
npm run dev --prefix frontend
```

Либо собрать фронтенд и раздавать его самим бэкендом (тогда достаточно одного
процесса, приложение будет на http://localhost:7878):

```bash
npm run build --prefix frontend
```

Бэкенд по умолчанию слушает `0.0.0.0:7878` (`FAM_BIND`), так что с телефона
в той же сети можно открыть `http://<ip-компьютера>:7878`.

Переменные окружения:
- `FAM_STATIC` - каталог со сборкой фронта
- `FAM_DATA` - путь к JSON состояния
- `FAM_BIND` - адрес listen (например `127.0.0.1:7878`)
- `FAM_CORS_ORIGINS` - allowlist origin через запятую (пусто = без CORS *)

Деплой на home-сервер: unit `deploy/fam.service`, обновление
`scripts/update-fam.sh`. Скрипт проверяет `index.html`, публикует фронтенд в
версионный каталог `frontend/releases/…` и атомарно переключает симлинк
`frontend/dist`. Существующий обычный каталог `dist` при первом обновлении
сохраняется как legacy-релиз; старые релизы и `fam-data.json` не удаляются.

## Данные

Состояние хранится в `fam-data.json` рядом с местом запуска бэкенда (путь можно
задать через `FAM_DATA`). Запись атомарная: tmp + fsync + rename; перед
перезаписью крутятся копии `fam-data.json.bak.0` … `.bak.4`. Битый файл
откладывается в `fam-data.json.corrupt`. Ошибка записи на мутациях даёт HTTP 503.
Удалите файл данных, чтобы начать с чистого листа.
